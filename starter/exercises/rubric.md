# Panduan umpan balik formatif Lab 01

Latihan ini tidak menghasilkan nilai atau penyerahan Lab 01 tersendiri. Dosen dan kelompok dapat memakai daftar berikut untuk meninjau kesiapan konsep sebelum menerapkannya pada satu proyek besar. Bobot resmi hanya mengikuti RPS/LMS dan [brief proyek kelompok](../../PROYEK_KELOMPOK.md).

## Bukti latihan yang bisa diperiksa

- Repo latihan dan commit dapat dibuka; tidak ada data pribadi, token, atau `.env` yang terunggah.
- `student.json` aman, `npm test` lulus, dan halaman lokal berjalan.
- `/api/hello` dan `/api/recommend` memberi HTTP 200 pada input benar serta 400 pada faktor tidak dikenal.
- Worksheet menyebut model layanan/deployment per komponen, sedikitnya tiga faktor keputusan, satu alternatif, dan trade-off.
- Deployment Vercel dan GitHub Actions boleh dicoba bila akun/kuota tersedia.

## Pertanyaan umpan balik

1. Apakah arsitektur dipecah menjadi komponen dengan tanggung jawab yang jelas?
2. Apakah keputusan merujuk kebutuhan pengguna, biaya, pola traffic, keamanan, dan kemampuan tim?
3. Apakah alternatif yang ditolak serta konsekuensinya dijelaskan jujur?
4. Konsep apa dari latihan ini yang akan digunakan pada proyek kelompok?

Jawaban antarkelompok boleh berbeda bila alasan teknis dan trade-off-nya dapat dipertanggungjawabkan.
